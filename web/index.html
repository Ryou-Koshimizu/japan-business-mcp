      03 / INSTALL
      
      
      導入
      
      
      実行ファイルを置いて、使っているアプリの設定に1か所書き足すだけです。外部の API の鍵は要りません。
      
    
      
    
      
      
      
        1
        
      
          
      実行ファイルを入れる
      
          
      go install github.com/Ryou-Koshimizu/japan-business-mcp/cmd/japan-business-mcp@latest
      
          
      GitHub の Releases に macOS・Linux・Windows 向けの実行ファイルも置いています。
      
        
      
      
      
      
      
        2
        
      
          
      アプリに登録する
      
          
      
            
            
            
            
          
      
          
      
            
      claude_desktop_config.json に足します。
      
            
      {
  "mcpServers": {
    "japan-business": {
      "command": "japan-business-mcp"
    }
  }
}
      
          
      
          
      
            
      ターミナルで1行。
      
            
      claude mcp add japan-business -- japan-business-mcp
      
          
      
          
      
            
      .cursor/mcp.json（プロジェクト）か ~/.cursor/mcp.json に足します。
      
            
      {
  "mcpServers": {
    "japan-business": {
      "command": "japan-business-mcp",
      "args": ["-calendar", "company-calendar.json"]
    }
  }
}
      
          
      
          
      
            
      Streamable HTTP で待ち受けます。外に出すときは JBIZ_HTTP_TOKEN で鍵を掛けます。
      
            
      JBIZ_HTTP_TOKEN=change-me japan-business-mcp -http 127.0.0.1:8105
# → http://127.0.0.1:8105/mcp
      
          
      
        
      
      
      
      
      
        3

      「来月の支払予定を、月末締め翌月末払い・休みなら前営業日で出して」
      
          
      「この請求書、インボイスとして足りないところはある？」
